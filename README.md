# cedana-propagator-sdk

Multi-language SDKs for the [Cedana](https://cedana.ai) Propagator API, generated
with [kiota](https://github.com/microsoft/kiota) from a shared OpenAPI spec.

| Language | Path                   | Install                                                                          |
| -------- | ---------------------- | -------------------------------------------------------------------------------- |
| Go       | [`go/`](./go)          | `go get github.com/cedana/cedana-propagator-sdk/go`                              |
| Python   | [`python/`](./python)  | `pip install "git+https://github.com/cedana/cedana-propagator-sdk.git#subdirectory=python"` |

See each language directory's README for usage and error-handling docs.

## Layout

- `openapi.json` — the single source of truth for all SDKs, copied from
  cedana-propagator (generated by its `generate_openapi_json` test).
- `<language>/` — one directory per language, each with its own `generate.sh`
  and a small amount of hand-written convenience code that kiota does not
  touch (client constructors, error helpers).
- `generate.sh` — regenerates every language from the root spec.

## Regenerating

```sh
./generate.sh          # all languages
./go/generate.sh       # just Go
./python/generate.sh   # just Python
```

Requires docker (kiota runs via the pinned `mcr.microsoft.com/openapi/kiota`
image).

Note that a spec downloaded from a running deployment is semantically identical
to the test-generated one but serializes keys in a different order, so
regenerating from it produces a large `openapi.json` diff and new
`descriptionHash` values in the `kiota-lock.json` files while leaving the
generated code unchanged. Prefer the test-generated spec to keep diffs
reviewable.

## Automation

This repo is updated automatically by
[cedana-propagator](https://github.com/cedana/cedana-propagator) CI: every push
to its `main` regenerates all SDKs here and commits the result, and every
propagator tag is mirrored into this repo pointing at the matching SDK commit.
Manual commits are only needed for the hand-written files.
